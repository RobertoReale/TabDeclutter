# TabDeclutter — Build instructions and notes for AMO review

The Firefox bundle is generated by Vite (through WXT), so AMO requires the source code and the means
to rebuild it. This file is that.

## Environment

| Item             | Value                                                                   |
| ---------------- | ----------------------------------------------------------------------- |
| Operating system | Windows 11 (the published builds); any OS supported by Node also works  |
| Node.js          | **24.13.0** (`.nvmrc`)                                                  |
| pnpm             | **11.17.0** (`packageManager` in `package.json`; `corepack enable` installs it) |
| Lockfile         | `pnpm-lock.yaml`, committed; every dependency version is pinned exactly |

`tests/unit/store-docs.test.ts` checks that the two versions above equal `.nvmrc` and
`packageManager`.

## Build commands

```sh
pnpm install --frozen-lockfile
pnpm build:firefox
```

The result is `.output/firefox-mv3/`, the content of the add-on. `pnpm zip:firefox` runs the same
build and writes the add-on zip and the sources zip. The sources zip holds no minified or
generated code, no `.output/` and no `node_modules/`.

`pnpm install` runs a `postinstall` step that also downloads Chromium for the test suites
(`playwright install chromium`). It is not used by the build and does not touch the output.

## Notes for reviewers

```
TabDeclutter suggests which tabs to close, organizes the rest into native tab groups and blocks duplicate tabs in real time. Everything stays on the device.

Permissions:
- tabs: reads the URL, title and last-used time of the open tabs. It is the whole input of the extension. Nothing is read from page content: there are no content scripts and no host permissions.
- tabGroups: creates and names native tab groups.
- storage: settings, the tab activity map, the archive of closed tabs and the whitelist, in local storage only.
- alarms: periodic cleanup of the archive, badge refresh, end of a pause of the duplicate protection.
- sessions: restores a closed tab with its history on "Undo".
- menus: right-click menu items.
- bookmarks (optional): requested only if the user turns on the "already bookmarked" signal; read-only.

No network requests of any kind, no analytics, no remote code, no eval or new Function. data_collection_permissions is "none". Incognito is not allowed.

How to test: install, then open the sidebar from the toolbar button or Alt+Shift+D. "Riordina" (Declutter) lists tabs with the reason each is suggested. "Organizza" groups the open tabs by site. In the settings, "Protezione duplicati" (Duplicate protection) set to close automatically: open the same page twice and the newer tab is closed and the older one is activated; "Annulla" (Undo) reopens it. The language follows the browser (Italian or English) and can be changed in the settings.

The on-device AI grouping uses Chrome's Prompt API and does not exist on Firefox. The add-on is built with WXT, Vite and Preact; the instructions to rebuild it are in docs/AMO_REVIEW.md. Every source file is in the sources zip.
```

## web-ext lint

`pnpm lint:firefox` (`web-ext lint -s .output/firefox-mv3`) must report 0 errors; it is a gate. Any
warning is listed with its assessment in `docs/DECISIONS.md` or in the release checklist.

## Reproducibility

The Firefox package and the package rebuilt from the sources zip, with the versions above, are
meant to be identical. The release task that checks this (rebuild from the sources zip and diff
against the add-on zip) is M7.5; until it is done this file claims the instructions, not the
result.
